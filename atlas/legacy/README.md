# Legacy web compatibility lab

This folder covers two frameworks that still appear in older enterprise/mobile-platform job descriptions.

- **AngularJS 1.x**: a tiny live status console using controllers, dependency injection and `$http`.
- **SproutCore**: a minimal application namespace, controller and `SC.Page`/view hierarchy.

These are intentionally isolated from the modern Next.js UI. The point is to demonstrate that an older codebase can be read, debugged and extended without dragging legacy framework choices into new product code.
